# Трафарет паттерна нарушения

Каждый паттерн — одна YAML-карточка в этой папке. Ядро системы читает карточки
и собирает из готовых блоков; код конвейера при добавлении паттерна не меняется.

## Категории нарушений

Любое нарушение — одна из пяти базовых категорий или их комбинация (составное нарушение).
Категория определяет, какой сигнал система должна увидеть и как его ловить.

| Категория (`category`) | Что ловим | Как ловим | Новое нарушение = |
|---|---|---|---|
| `environment` — состояние среды | огонь, дым; далее разлив, утечка, загромождённый проход | детектор/сегментация + зона + длительность | новый класс в `yolo-det` + карточка |
| `behavior` — поведение во времени | бег, падение, перелезание, пролезание, подъём спиной | трек → окно скелета 1–2 с → классификатор поведения | новый класс в `behavior_v1` + карточка |
| `zone` — положение относительно зоны | опасная зона, под грузом, рука у щита, зона «высота» | ключевая точка + полигон/линия + время, без модели | разметка зоны в интерфейсе + карточка |
| `interaction` — взаимодействие | сближение с техникой, драка | пара треков: расстояние в ростах, скорость; `pair_v1` | новый тип участника/класс пары + карточка |
| `attribute` — экипировка и атрибуты | каска, жилет, перчатки, привязь; телефон, сигарета | вырезка части тела → `crop_attr_v1`, кэш по треку | новая голова/класс в `crop_attr_v1` + карточка |

Составные примеры: пронос груза без спецодежды = `behavior + attribute`;
голые руки у проводов = `zone + attribute`; работа на высоте без привязи = `zone + attribute`.

Цена добавления нового нарушения: только настройка (зоны и комбинации существующего)
или новый класс в общей модели. Конвейер не меняется.

## Поля карточки

| Поле | Что задаёт |
|---|---|
| `id`, `name` | Идентификатор и название для интерфейса |
| `category` | Одна или несколько категорий (см. выше) |
| `severity` | `critical` — сразу диспетчеру, со звуком; `warning` — в ленту и мастеру |
| `target` | Чей это паттерн: `person` (трек человека), `pair` (пара треков), `object` (объект в зоне) |
| `conditions` | Список условий. По умолчанию все должны выполниться на одном треке (И). Группа `any_of` — хотя бы одно (ИЛИ) |
| `confirm` | Подтверждение во времени: `window_sec` — окно, `n_of_m` — сколько окон из скольких, `hold_sec` — сколько держится |
| `zones` | `include` — где правило активно (пусто = везде), `exclude` — где игнорируется |
| `dedup` | `per: track` — одно событие на трек; `per: zone` — на зону; `cooldown_sec` — блокировка повторов по ключу камера+зона+тип |
| `notify` | Кому: `dispatcher`, `master`, `ot_specialist` |
| `schedule` | Когда активно: `always` или интервал, например `"07:55-12:00"` |
| `evidence` | Доказательства: кадр и клип `[секунд до, секунд после]` |
| `status` | `mvp`, `second`, `backlog` — очередь реализации |

## Четыре блока

| Блок | Вход | Параметры |
|---|---|---|
| `object_zone` | Детектор/сегментация без людей | `model`, `classes`, `min_area_px` |
| `person_sequence` | Окно скелета одного трека | `model` + `class` + `min_score`; пока модель не обучена — `fallback_rule` |
| `pair_interaction` | Два трека | `other: vehicle/person`, `max_distance_h` (в ростах человека), `model`/`class` для драки |
| `bodypart_crop` | Вырезка по точкам позы | `part: hand/face_hand/torso/head`, `model`, `class`, `min_score` |

Служебные условия: `in_zone` (точка тела в полигоне), `cross_line` (трек пересёк линию),
`still` (нет движения N секунд).

## Модели: всего четыре, общие для всех карточек

Карточки не запускают модели сами. Модели работают один раз, а все карточки читают их общие выходы.
Движок вычисляет только то, что нужно включённым на камере карточкам, и сначала проверяет дешёвые
условия (зона, поведение), а вырезки классифицирует только для кандидатов, с кэшем по треку.

| Модель | Когда запускается | Выходы (классы) |
|---|---|---|
| `yolo-pose` | каждый обрабатываемый кадр | люди + 17 ключевых точек COCO |
| `yolo-det` | каждый кадр или каждый N-й | `forklift`, `vehicle`, `load`, `fire`, `smoke` |
| `behavior_v1` (1D-CNN по скелету, softmax) | раз в 0,5 с на трек | `normal`, `run`, `fall`, `climb`, `crawl`, `hand_to_mouth`, `carry`, `lift_back` |
| `crop_attr_v1` (ResNet-18 / EfficientNet-B0, многоголовый) | только для кандидатов, кэш по треку | кисть: `empty`/`phone`/`cigarette`/`glove`/`bare_hand`; голова: `helmet`/`no_helmet`; торс: `vest`/`no_vest`, `harness`/`no_harness` |
| `pair_v1` (опционально) | только когда два трека рядом | `normal`, `fight` |

## Как добавить новый паттерн

1. Скопировать похожую карточку.
2. Выбрать блоки в `conditions` и указать модель/класс (или правило-заглушку).
3. Задать зоны, подтверждение, уровень и получателей.
4. Включить паттерн в конфиге нужной камеры. Перезапуск конвейера не нужен.
