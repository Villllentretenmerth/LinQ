## Что было не так и что поменяли

1. **Снимали с рук, камера «гуляет» на 30–200 px.** Каждый ролик выровнен к первому кадру гомографией по ORB: `core/tools/stabilize.py`. С неподвижной камерой этот шаг не нужен.
2. **Бег 0 из 3.** Скорость считалась в ростах в секунду в кадре. Если человек бежит прямо на камеру, он почти не смещается по кадру, а растёт: 0,3–1,0 роста/с при пороге 1,5.
   - Добавили калибровку пола камеры: в конфиге 4 точки на полу и их координаты в метрах.
   - Новый признак `floor_speed_mps` — скорость по полу в м/с. Шаг 1,2–1,6 м/с, быстрый шаг — до 2,2 м/с. Бег — пики 2,7–2,9 м/с, большую часть забега выше 2,3 м/с.
   - Правило: `floor_speed_mps > 2.3 or speed_heights_per_sec > 1.5`. Подтверждение 1,0 с, 2 из 3 вместо 1,5 с, 3 из 4: забег длится всего 2–3 с.
3. **Падение «вдоль взгляда» камеры (v07) пропускалось.** Человек лёг головой к камере, и наклон корпуса в кадре остался около 10°.
   - По той же калибровке посчитали, каким был бы стоящий человек в этой точке пола: `height_vs_standing` (1 — стоит, около 0,45 — лежит).
   - Признак `stand_drop` показывает, насколько резко человек «осел» за 1 с.
   - Правило: `... or (height_vs_standing < 0.6 and stand_drop > 0.55)`.
   - Сесть на пол медленнее (0,46), присесть — не так низко (0,66).
4. **Ложное «подъём спиной» в момент падения (v05).** В правило добавили `hips_height_ratio > 0.3`: бёдра высоко, человек не лежит.

Калибровка пола: стоящий человек ростом 1,8 м даёт сторону квадрата из бутылок около 2,9 м. Скорость ходьбы сходится: 1,2–1,6 м/с. **Сторону квадрата лучше замерить рулеткой.**

## Что в папке

- `demo_cp3.mp4` — демо на 47 с: зона с двумя людьми, падение и второй этап, бег, подъём спиной, две ловушки, итог.
- `eval/labels.csv` — разметка по просмотру роликов, независимо от конвейера. `eval/clips.yaml` — зоны и калибровка пола для каждого ролика.
- `eval/quality_before.md`, `eval/quality_after.md` — отчёты; `eval/events_after.jsonl` — все события с временем в ролике.
- `patch/` — изменённые файлы в структуре репозитория друга. `patch/changes.diff` — дифф к архиву.

## Как повторить

```
python -m core.tools.stabilize clips_raw/v02.mp4 clips/v02.mp4          # для каждого ролика, снятого с рук
python -m core.tools.eval_clips --clips clips/clips.yaml --out out/eval --cache out/cache --video
python -m core.tools.evaluate --labels clips/labels.csv --events out/eval/events.jsonl --report out/eval/quality.md
```

С `--cache` выходы моделей сохраняются, и повторный прогон с другими порогами занимает около 20 с вместо 13 мин.

С `--patterns-dir` можно сравнить другую папку карточек.

В камеру из `cameras.yaml` калибровку пола добавляют так (без неё карточки работают как раньше):

```yaml
floor: { image: [[640, 385], [910, 497], [604, 738], [350, 479]], world_m: [[0, 0], [2.9, 0], [2.9, 2.9], [0, 2.9]] }
```
