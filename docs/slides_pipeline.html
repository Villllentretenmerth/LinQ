Подтверждение и дедупликация

Одно нарушение — одно оповещение

1

Расписание и зоны

Карточка работает только там и тогда, где нужно: зона у стеллажей — до 12:00

2

N из M окон

Скользящие окна 0,5–2 с: тревога, только если нарушение видно в N окнах из M. Одиночный кадр её не вызовет

3

Удержание

Нарушение должно продлиться hold_sec: прошёл мимо зоны — не нарушение

4

Без повторов

Одно событие на трек и блокировка повторов по «камера + зона + тип» — даже если трекер сменил ID

пример: падение
0 с
человек стоит — копится история трека
3 с
падает: корпус наклонён больше 60°, центр тела опустился больше чем на 0,4 роста
5 с
тревога диспетчеру — событие и кадр в журнале
13,5 с
лежит без движения 10 с — признак потери сознания, второй этап события
Время до тревоги:
сближение с техникой ~1 с
падение ~2 с
бег ~2,5 с
опасная зона ~3 с
